┌────────────────────────────────────────────────────────────────────┐
│ YANG ANDA BUTUHKAN SEBELUM MULAI                                     │

  ✔ Akun hosting IDwebhost yang sudah aktif (sudah bayar)
  ✔ Nama domain (contoh: mitloin.com) yang sudah terhubung ke hosting

        - api.php
        - config.php

┌────────────────────────────────────────────────────────────────────┐
│ LANGKAH 0 — LOGIN KE CPANEL IDWEBHOST                                │
└────────────────────────────────────────────────────────────────────┘

  1. Buka browser, ketik salah satu alamat ini:
        https://namadomainanda.com/cpanel
        atau
        https://namadomainanda.com:2083
        (alamat persisnya ada di email aktivasi dari IDwebhost)

  2. Masukkan Username & Password cPanel (dari email IDwebhost)

  3. Setelah masuk, Anda akan lihat banyak ikon menu. Inilah cPanel.

  TIP: Bisa juga login lewat Member Area IDwebhost → klik produk
       hosting Anda → tombol "Login cPanel".


┌────────────────────────────────────────────────────────────────────┐
│ LANGKAH 1 — BUAT DATABASE (pakai "MySQL Database Wizard")            │
└────────────────────────────────────────────────────────────────────┘

  Cara termudah pakai WIZARD (dipandu langkah demi langkah):

  1. Di cPanel, cari kotak pencarian atas, ketik: MySQL
  2. Klik menu  "MySQL® Database Wizard"

  ── Step 1: Create A Database ──
  3. Isi nama database, contoh ketik:  mitloin
     (nama lengkapnya nanti otomatis jadi seperti: useridwh_mitloin)
  4. Klik tombol  "Next Step"

  ── Step 2: Create Database Users ──
  5. Isi Username, contoh ketik:  admin
     (nama lengkapnya jadi seperti: useridwh_admin)
  6. Klik tombol  "Password Generator" → akan muncul password kuat
     → centang "I have copied this password" → klik "Use Password"
     → ATAU ketik password sendiri di kolom Password & ulangi.

     ⚠ PENTING: CATAT 3 hal ini di notepad, akan dipakai di Langkah 3:
          • Nama database lengkap : useridwh_mitloin
          • User database lengkap : useridwh_admin
          • Password              : (yang barusan)

  7. Klik  "Create User"

  ── Step 3: Add User to Database ──
  8. Akan muncul daftar hak akses (privileges).
  9. Centang kotak  "ALL PRIVILEGES"  (paling atas — otomatis
     mencentang semua yang lain)
  10. Klik  "Next Step"

  ✅ Selesai. Database & user sudah jadi.


┌────────────────────────────────────────────────────────────────────┐
│ LANGKAH 2 — EDIT FILE config.php DI KOMPUTER                         │
└────────────────────────────────────────────────────────────────────┘

  Lakukan ini di KOMPUTER Anda dulu (sebelum upload).

  1. Klik kanan file config.php → Open With → Notepad++ (atau VS Code)

  2. Cari baris-baris ini, ganti isinya pakai data dari Langkah 1:

        define('DB_HOST', 'localhost');
        define('DB_NAME', 'useridwh_mitloin');   ← nama database lengkap
        define('DB_USER', 'useridwh_admin');     ← user database lengkap
        define('DB_PASS', 'password_dari_wizard'); ← password tadi

     CATATAN: DB_HOST di IDwebhost biasanya tetap 'localhost'
              (tidak perlu diubah). Kalau tidak jalan, coba ganti
              menjadi '127.0.0.1'.

  3. Cari baris SECRET_KEY, ganti dengan teks acak panjang buatan Anda:

        define('SECRET_KEY', 'mitloin_R4h4s14_2026_xY9pQ_jangan_dibagi');

  4. Cari baris ALLOWED_ORIGIN, ganti dengan domain Anda:

        define('ALLOWED_ORIGIN', 'https://www.namadomainanda.com');

     (Pakai https:// dan TANPA garis miring / di akhir)

  5. SIMPAN file (Ctrl+S). Jangan ubah nama file-nya.


┌────────────────────────────────────────────────────────────────────┐
│ LANGKAH 3 — IMPORT database.sql (pakai phpMyAdmin)                   │
└────────────────────────────────────────────────────────────────────┘

  1. Kembali ke cPanel → kotak pencarian → ketik: phpMyAdmin
  2. Klik menu  "phpMyAdmin"  (akan buka tab baru)

  3. Di panel KIRI, klik nama database Anda (useridwh_mitloin)
     → harus dalam kondisi masih kosong (belum ada tabel)

  4. Di menu ATAS, klik tab  "Import"

  5. Pada bagian "File to import" → klik  "Choose File" / "Pilih File"
     → cari & pilih file  database.sql  di komputer Anda

  6. Biarkan pengaturan lain default. Scroll ke bawah.
  7. Klik tombol  "Import" / "Go" / "Kirim"

  8. TUNGGU sampai muncul tulisan HIJAU:
        "Import has been successfully finished"

     ✅ Kalau hijau = berhasil. Di panel kiri akan muncul tabel-tabel
        seperti: users, produk, pesanan, kategori, pengaturan, dll.

  ❌ Kalau muncul ERROR MERAH → lihat bagian TROUBLESHOOTING di bawah.


┌────────────────────────────────────────────────────────────────────┐
│ LANGKAH 4 — EDIT API_BASE_URL DI mitloin.html                        │
└────────────────────────────────────────────────────────────────────┘

  Masih di KOMPUTER (sebelum upload mitloin.html).

  1. Buka mitloin.html dengan Notepad++ / VS Code
     (file besar ~11 MB, tunggu sebentar saat membuka)

  2. Tekan Ctrl+F → ketik:  API_BASE_URL  → Enter
     Anda akan menemukan baris seperti:

        const API_BASE_URL = 'https://domainanda.com/backend/api.php';

  3. Ganti URL-nya. Karena semua file akan ditaruh di folder utama
     (public_html), maka isinya cukup:

        const API_BASE_URL = 'https://www.namadomainanda.com/api.php';

     (Ganti "namadomainanda.com" dengan domain asli Anda)

  4. SIMPAN (Ctrl+S).


┌────────────────────────────────────────────────────────────────────┐
│ LANGKAH 5 — UPLOAD SEMUA FILE (pakai File Manager cPanel)            │
└────────────────────────────────────────────────────────────────────┘

  1. Kembali ke cPanel → kotak pencarian → ketik: File
  2. Klik menu  "File Manager"

  3. Di panel kiri, klik folder  "public_html"
     (Ini folder utama website. Apapun yang ditaruh di sini langsung
      tampil di domain Anda.)

     ⚠ Kalau di dalam public_html sudah ada file "default" bawaan
       (misal index.html bawaan hosting), hapus/biarkan saja —
       nanti tertimpa.

  4. Klik tombol  "Upload"  di menu atas (akan buka tab baru)

  5. Klik  "Select File"  lalu pilih & upload satu per satu (atau
     pilih beberapa sekaligus) file berikut:

        ✔ mitloin.html        (besar ~11 MB — tunggu sampai 100%)
        ✔ admin-dashboard.html
        ✔ api.php
        ✔ config.php
        ✔ database.sql        (boleh diupload, atau tidak — opsional)

     TUNGGU progress bar tiap file sampai 100% (hijau).

  6. Setelah semua selesai, kembali ke File Manager
     → pastikan semua file ada di dalam public_html.

  💡 Kalau mitloin.html gagal/lambat lewat File Manager karena besar,
     pakai cara FTP (lihat bagian "CARA ALTERNATIF FTP" di bawah).


┌────────────────────────────────────────────────────────────────────┐
│ LANGKAH 6 — JADIKAN mitloin.html SEBAGAI HALAMAN UTAMA               │
└────────────────────────────────────────────────────────────────────┘

  Supaya saat orang buka namadomainanda.com langsung muncul website
  (bukan halaman kosong), lakukan SALAH SATU cara berikut:

  ── CARA MUDAH: Rename jadi index.html ──
  1. Di File Manager, klik kanan file  mitloin.html
  2. Pilih  "Rename"
  3. Ubah namanya menjadi:  index.html
  4. Klik "Rename File"

     ⚠ Karena namanya berubah jadi index.html, link dashboard tetap:
        https://www.namadomainanda.com/admin-dashboard.html

  ── CARA ALTERNATIF: Bikin pengalih (kalau tak mau rename) ──
  1. Di File Manager → klik "+ File" → beri nama: index.html
  2. Klik kanan index.html → Edit → tempel baris ini → Save:
        <meta http-equiv="refresh" content="0;url=mitloin.html">


┌────────────────────────────────────────────────────────────────────┐
│ LANGKAH 7 — AKTIFKAN HTTPS / SSL (WAJIB, GRATIS)                     │
└────────────────────────────────────────────────────────────────────┘

  Supaya website aman (ada gembok hijau) dan pembayaran dipercaya.

  1. Di cPanel → kotak pencarian → ketik: SSL
  2. Klik menu  "SSL/TLS Status"
  3. Centang domain Anda → klik  "Run AutoSSL"
  4. Tunggu beberapa menit sampai muncul tanda gembok/centang hijau.

  Di IDwebhost SSL Let's Encrypt biasanya sudah otomatis aktif.
  Kalau belum aktif setelah 1 jam, hubungi CS IDwebhost minta
  "aktifkan SSL Let's Encrypt" untuk domain Anda.

┌────────────────────────────────────────────────────────────────────┐
│ CARA ALTERNATIF FTP (kalau upload mitloin.html lambat/gagal)         │
└────────────────────────────────────────────────────────────────────┘

  1. Download aplikasi FileZilla (gratis) di filezilla-project.org
  2. Di cPanel → cari "FTP Accounts" → lihat detail / buat akun FTP
     atau pakai data ini:
        Host     : ftp.namadomainanda.com   (atau IP server dari email)
        Username : username cPanel Anda
        Password : password cPanel Anda
        Port     : 21
  3. Buka FileZilla → isi Host/Username/Password/Port → Quickconnect
  4. Panel kanan = server. Masuk ke folder  public_html
  5. Panel kiri = komputer Anda. Cari file mitloin.html
  6. Drag file dari kiri ke kanan → tunggu sampai selesai.


┌────────────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING (SOLUSI MASALAH UMUM)                                │
└────────────────────────────────────────────────────────────────────┘

  ❌ Website terbuka tapi KOSONG / putih
     → mitloin.html belum di-upload, atau belum di-rename index.html.
       Cek lagi Langkah 5 & 6.

  ❌ Produk tidak muncul / keranjang error
     → API_BASE_URL di mitloin.html salah. Pastikan persis:
       https://www.namadomainanda.com/api.php  (Langkah 4)
     → Tes buka langsung https://www.namadomainanda.com/api.php
       di browser — kalau muncul tulisan JSON, berarti api.php jalan.

  ❌ Login dashboard gagal / "kesalahan server"
     → Kredensial database di config.php salah. Cek ulang Langkah 2
       (DB_NAME, DB_USER, DB_PASS harus PERSIS sama seperti Langkah 1).

  ❌ Import database.sql ERROR MERAH di phpMyAdmin
     → Pastikan database dipilih dalam kondisi KOSONG.
     → Kalau error "max execution / file too large", import lewat
       menu cara lain: hubungi CS atau pecah file. Biasanya file
       database.sql ini kecil jadi jarang bermasalah.

  ❌ Muncul "CORS error" di Console browser (F12)
     → ALLOWED_ORIGIN di config.php tidak sama dengan domain.
       Samakan persis termasuk https:// dan www (Langkah 2).

  ❌ Upload foto QRIS di dashboard gagal / Error 500
     → Tabel "pengaturan" kolom nilai harus tipe MEDIUMTEXT.
       Sudah diatur otomatis di database.sql, jadi cukup pastikan
       import berhasil hijau.

  ❌ Belum ada gembok / "Not Secure"
     → SSL belum aktif. Ulangi Langkah 7 atau hubungi CS IDwebhost.
